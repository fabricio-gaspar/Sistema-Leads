# Telas que devem ser mapeadas, não assumidas como concluídas
- Dashboard: hierarquia de KPI, filtros, estados, densidade e consistência dos números.
- Leads/Busca/Kanban: ações, cartões, tabelas, responsividade, overflow e filtros consistentes.
- Central de Atendimento/Meu WhatsApp: chat, layout master-detail, conectividade, estados, avisos de erro e acessibilidade.
- Agenda/Orçamentos/Funil/Relatórios: datas, tabelas, métricas, exportações onde já existentes.
- Configurações/Usuários: formulários, permissões e telas críticas; nunca esconder bloqueio de segurança só para melhorar aparência.
- Avaliar barra lateral, cabeçalhos, modais, padrões de botões e toasts antes de propagar ajustes.
