# R11 — rotina delimitada e observabilidade honesta

Estado do lote completo: **PARCIAL**. Delta de código local validado; execução real de scheduler/Apify e configuração Auth permanecem não homologadas. Nenhuma cidade escolhida para o operador, busca paga, run real ou alteração de configuração remota.

## Prospecção

`AnaOperationSettings.city` e formulário oferecem cidade e uma única UF. Não se aceita uma lista de estados que seria truncada silenciosamente no consumidor. Para ativar: cidade de 2–120 caracteres, uma UF brasileira e ao menos um segmento/atividade válido. Não há geocodificação nem afirmação de correspondência cidade–UF.

`ana-operations` persiste `filters.cidade`, expõe readiness de localização e verifica save ativo, set_automatic, run_now não simulado e approve_run. Aprovar um run antigo valida **o schedule daquele run**, não o mais recente. Configuração candidata válida pode corrigir um rascunho antigo inválido sem ficar bloqueada pelo readiness anterior. Inativo/simulação podem registrar plano incompleto, mas não são apresentados como prova de execução real.

Migration `20261005225107_audit_r11_prospecting_location_guard.sql`: guards de schedule ativo e run awaiting_approval/queued/running não simulado, inclusive bypass por outro consumidor SQL. Trigger de run lê o parent da mesma organização sob `FOR SHARE`; funções privadas, grants mínimos. Não atualiza registros históricos nem ativa/cancela rotinas em produção. A guarda de cidade existente no provedor permanece como última barreira.

UI diferencia `simulated`, `awaiting_approval` e `queued` pelo resultado do servidor. Fila não significa busca concluída, HTTP 200 não significa entrega, e falha de transporte não promete que o estado anterior foi preservado.

## Métricas

O Registro do Sistema reutiliza a amostra real já retornada pelo backend (até 50 agent_runs e 50 jobs): tempo p95 entre criação/conclusão, quantidade failed/error e maior espera vencida observada. Exclui datas inválidas/negativas, agendamentos futuros e valores ausentes. Sem amostra aparece desconhecido, nunca zero fictício. O recorte, denominador e instante são explícitos: não representa taxa global, latência de rede, todo o backlog ou SLA.

Rótulos do status diferenciam heartbeat/presença do worker de resultado de negócio. Gates de ativação não foram liberados nem alterados silenciosamente.
